# スライダーアイテムの設計

## 高さ・パディング

- スタイルタブの「寸法」に、WordPress標準の高さ・パディングを追加する。各入力は初期非表示とし、値と単位はテーマおよびコアの設定に従う。高さの標準入力はWordPress 7.0以降で利用できる。
- 値は`style.dimensions.height`、`style.spacing.padding`に保存する。編集時と保存時の適用先はアイテムの外枠とする。個別解除や設定の初期化で、該当プロパティの既定のスタイルに戻る。
- 高さはアイテムの外枠にインラインで適用し、親の固定高さや縦横比がある場合もアイテム自身の高さを指定できる。高さの保存HTMLはプラグイン側で生成し、WordPressの標準寸法入力が導入される前のバージョンでも同じHTMLを再現できるようにする。
- 高さ・パディングを指定していない公開済みアイテムは、従来のHTMLで保存・読み込みできる。

## 枠線

- スタイルタブの「枠線」に、WordPress標準の色・角丸・種類・太さを追加する。各入力は初期非表示とする。
- 値は`style.border`（パレットの色は`borderColor`）に保存し、WordPressがアイテムの外枠に出力する。
- 枠線を指定していない公開済みアイテムは、従来のHTMLで保存・読み込みできる。

## 幅を設定に含めない理由

- アイテムの幅が効くのは、親の「1画面に表示するスライド数」が`auto`の範囲だけになる。表示数が数値の範囲では、Swiperが表示数と間隔から各スライドの幅を計算して上書きする。
- 幅の入力を親の表示数に合わせて表示・非表示にするには、端末別の表示数の判定、保存値がある場合の表示、ブロックサポートの入力を切り替えるフィルターが必要になる。設定の複雑さに見合わないため、通常の幅・端末別の幅とも採用しない。
