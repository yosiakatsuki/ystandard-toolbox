# スライダーアイテムの設計

## 幅・高さ・パディング

- スタイルタブの「寸法」に、WordPress標準の幅・高さ・パディングを追加する。各入力は初期非表示とし、値と単位はテーマおよびコアの設定に従う。幅・高さの標準入力はWordPress 7.0以降で利用できる。
- 値は`style.dimensions.width`、`style.dimensions.height`、`style.spacing.padding`に保存する。編集時と保存時の適用先はアイテムの外枠とする。個別解除や設定の初期化で、該当プロパティの既定のスタイルに戻る。
- 幅はCSSカスタムプロパティで渡し、Swiperが端末別の表示数を数値から`auto`へ切り替えても、保存値を参照できるようにする。フロントでの幅の優先順位は[親の設計](../slider/DESIGN.md)に従う。
- 高さはアイテムの外枠にインラインで適用し、親の固定高さや縦横比がある場合もアイテム自身の高さを指定できる。幅と高さの保存HTMLはプラグイン側で生成し、WordPressの標準寸法入力が導入される前のバージョンでも同じHTMLを再現できるようにする。
- 幅・高さ・パディングを指定していない公開済みアイテムは、従来のHTMLで保存・読み込みできる。
