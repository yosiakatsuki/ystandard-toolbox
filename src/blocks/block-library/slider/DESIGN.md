# スライダーの設計

## 上下マージン

- スタイルタブの「寸法」で、WordPress標準の余白設定から上と下のマージンを追加できる。入力は初期非表示とし、値と単位はテーマおよびコアの設定に従う。
- `style.spacing.margin.top`と`style.spacing.margin.bottom`に保存し、編集画面とフロントの外枠に適用する。個別解除や設定の初期化で、テーマと既存のスタイルによる余白に戻る。

## 初期化前の表示

- Swiperの初期化前は1枚目のスライドだけを表示し、初期化後に表示数・中央寄せ・ループの配置へ切り替わる。この切り替わりを見せないため、初期化前のスライダー本体（ナビゲーション・ページネーションを含む）を透明にし、初期化後にフェードインする。動きを減らす設定の利用者にはフェードを使わない。
- 初期化前も1枚目のスライドで高さを確保し、後続のコンテンツを動かさない。初期化前後でスライドの高さが変わる場合は、その差だけ縦にずれる。
- スクリプトが動かない場合も見えないままにならないよう、3秒後にCSSアニメーションで表示する。エディターでは透明にしない。
- 表示数・間隔から初期化前の配置を再現する方法は、端末別の値を保存HTMLの外から渡す必要があり、エフェクトごとの対応も要るため採用していない。

## 矢印（ナビゲーション）のスタイル

### 設定の配置

- 設定タブの「矢印（ナビゲーション）」には表示の切り替えだけを置く。`ToolsPanel`の項目「表示」を最初から表示し、個別解除・全解除で非表示に戻す。
- デザイン・矢印の色・背景色・大きさはCSSプロパティを制御するため、スタイルタブの「矢印（ナビゲーション）」にまとめる。端末別の大きさは、その後ろの「レスポンシブ矢印サイズ」に分ける。
- スタイルタブの「矢印（ナビゲーション）」「レスポンシブ矢印サイズ」の項目は、共通設計の例外としてすべて最初から表示する。項目を追加メニューに隠すと設定できる内容が分かりづらいため。背景色はデザインが四角・円のときだけ表示する。デザインが未設定のときは「既定」を選んだ状態で表示する。
- 「レスポンシブ矢印サイズ」は、共有の`ResponsiveSizePanel`に`shownByDefault`で幅の項目を指定して最初から表示する。
- 矢印の色・背景色は、コアの色パネルと同じく行間のないラッパーで囲み、項目どうしで枠線を共有して表示する。
- 矢印の色は設定タブから移した。移したのはUIだけで、保存先の`navigationColor`・`customNavigationColor`は変えていない。
- スタイルタブの2つのパネルは、矢印を表示する場合だけ出す。表示を切ったときも、保存した値は消さない。
- 「矢印（ナビゲーション）」はこのブロックにしかない選択肢で構成するため、ブロック側（`inspector-controls/styles/navigation/`）に置く。「レスポンシブ矢印サイズ」は共有の`ResponsiveSizePanel`で幅の項目だけを有効にし、項目名を「矢印の大きさ」に差し替えて使う。返った幅の値を`responsive.size`へ保存する。

### デザイン

- 「既定」「四角」「円」から選ぶ。既定は従来の表示で、`style.ystdtb.slider.navigation.design`を保存しない。四角は`square`、円は`circle`を保存する。
- 四角・円は、ボタン（`--swiper-navigation-size`の正方形）に背景を付け、矢印をボタンの高さの4割で中央に置く。角丸は四角が4px、円が50%。
- ボタンに`ystdtb-slider__navigation--{design}`クラスを付けて切り替える。
- 背景の中で矢印が中央に見えるよう、矢印の位置を左右に調整する。四角・円とも、矢印が向く方向へ2%動かす（次へは`translate: 2% 0`、前へは`translate: -2% 0`）。前へボタンの矢印はSwiperが`transform`の回転で左向きにしているため、回転と重ならない`translate`で動かし、前へと次へで符号を逆にする。

### 背景色

- 四角・円のときだけ入力を表示する。未指定のときは白（`--ystdtb--color--white`）を使う。
- パレットの色は`navigationBackgroundColor`にスラッグ、それ以外は`customNavigationBackgroundColor`に色を保存する。矢印の色と同じ形式で、一方を保存するともう一方は消す。
- パレットの色は`has-{slug}-background-color`クラス、任意の色はインラインの`background-color`で出力する。テーマ側で`has-background`に余白が付く場合があるため、`has-background`クラスは付けない。
- 四角・円から既定へ戻すと、効かなくなる背景色も消す。既定のデザインでは背景色を出力しない。

### 色の不透明度

- 矢印の色・背景色とも、任意の色では不透明度を指定できる。不透明度付きの値（例：`#1565a080`）は任意の色として`customNavigationColor`・`customNavigationBackgroundColor`に保存する。
- パレットの色はクラスで出力するため、不透明度を持たない。パレットの色を選んだ後に不透明度を変えると、任意の色として保存する。
- 操作できない矢印にSwiperが付ける半透明表示（`opacity: 0.35`）は、指定した不透明度に重なる。

### 大きさ

- ボタン全体の大きさ（`--swiper-navigation-size`）を上書きする。既定のデザインでは矢印の高さ、四角・円では背景の一辺になる。未指定ならSwiperの既定（44px）。
- 通常の大きさは`style.ystdtb.slider.navigation.size`に保存し、ボタンのインラインスタイルへ出力する。
- 端末別の大きさは`style.ystdtb.slider.navigation.responsive.size.{desktop|tablet|mobile}`に保存し、ボタンへ`--ystdtb--{device}--slider--navigation-size`として出力する。PHP側で`Styles`の端末範囲を使い、値のある端末だけ`--swiper-navigation-size`を上書きする。未指定の端末は通常の大きさ、または既定に戻る。端末間で値は引き継がない。

### 互換性と制約

- 新しい設定を使わないスライダーは、保存HTMLが変わらない。deprecatedは追加しない。
- エディターには矢印を表示していないため、スタイルの設定はフロントで確認する。

## ズームアニメーション

### 設定

- 設定タブで「基本設定」のすぐ後に「ズームアニメーション」パネルを置く。エフェクトがフェードで、自動再生がONのときだけ表示する。条件から外れても保存した値は消さず、出力だけを止める。
- `ToolsPanel`で「種類」「拡大率」「動き方」を持つ。項目はすべて最初から表示する。拡大率・動き方は、種類がズームイン・ズームアウトのときだけ表示する。
- 種類は「なし / ズームイン / ズームアウト」から選び、`zoomAnimation`に`in`・`out`を保存する。「なし」は保存しない。
- 拡大率は101〜150%を1%刻みで選び、`zoomAnimationScale`に%で保存する。未指定は110%。
- 動き方は「指定なし / ease / ease-in / ease-out / ease-in-out」から選び、`zoomAnimationEasing`に保存する。「指定なし」は保存せず、`linear`で動かす。スライド効果とは「指定なし」の意味が違うため、選択肢は別に持つ。
- 種類の個別解除と全解除では、拡大率・動き方もまとめて消す。拡大率・動き方は種類がないと効かないため。拡大率・動き方の個別解除では、その値だけを消す。
- 属性に`default`は持たない。既存のスライダーの属性とfixtureを変えないため。

### 出力

- フェード・自動再生ON・種類の指定がそろったときだけ、ラップに`has-zoom-animation--{in|out}`クラスと、次のCSS変数を出力する。
  - `--ystdtb-slider--zoom-scale`：拡大率を倍率にした値（例：`1.1`）
  - `--ystdtb-slider--zoom-duration`：自動再生の間隔＋切り替え速度×2（ミリ秒）。フェードイン・表示・フェードアウトの間ずっと動かすため
  - `--ystdtb-slider--zoom-easing`：動き方。指定したときだけ出力する
- 条件を満たさないスライダーは保存HTMLが変わらないため、deprecatedは追加しない。

### 動き

- ズームインは等倍から拡大率まで、ズームアウトは拡大率から等倍までズームする。`transform`と重ならない`scale`を使う。
- ズームするのは、画像ブロックの`img`、動画ブロックの`video`、カバーブロックの背景画像・背景動画とする。スライダーアイテムの中にあるものも含む。カバーの文字はズームしない。スライド自体は、Swiperのフェードが`transform`を使うためズームしない。
- はみ出した部分は、画像・動画・カバーの枠で`overflow: hidden`にして隠す。
- 画像ブロックの角丸・枠線は`img`に付くため、ズームすると`figure`の枠で四角く切り取られ、角丸・枠線が見えなくなる。画像の装飾ごとにスクリプトで補正すると対応が増え続けるため、補正はしない。角丸・枠線を付けたい場合は、[スライダーアイテム](../slider-item/DESIGN.md)に角丸・枠線を付けて「はみ出した部分を隠す」をオンにし、その中に装飾のない画像を入れる運用とする。設定パネルには説明を出さず、公式サイトのマニュアルで補足する。
- `.swiper-slide-active`だけで動かすと、フェードアウトの途中でズームが解除され、画像が元の大きさに戻って見える。そのためフロントのスクリプトで`is-zoom-active`クラスを付け替える。初期化時と切り替えの開始時に表示中のスライドへ付け、切り替えの終了時に表示中以外のスライドから外す。
- 動きを減らす設定の利用者には、アニメーションを出さず等倍で表示する。
- エディターでは`is-zoom-active`を付けないため、アニメーションは再生しない。動きはフロントで確認する。

## ページネーションのクリック操作

- ドット（通常・ダイナミック）のページネーションは、クリックでスライドを切り替えられる。Swiperの`pagination.clickable`は既定で無効なため、フロントの初期化時に有効にする。
- 保存HTMLの`data-slider-options`には含めない。保存形式を変えずに、公開済みのスライダーにも適用するため。分数・プログレスバーでは、Swiperがこの指定を使わない。

## スライダー本体と子の高さ

- 既存の高さ・縦横比設定はスライダー本体の表示領域を制御する。[スライダーアイテム](../slider-item/DESIGN.md)の高さは子の外枠に適用する。
- 子には幅の設定を設けない。理由は子の設計に記載する。
