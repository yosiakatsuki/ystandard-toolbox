# スライダーの設計

## 上下マージン

- スタイルタブの「寸法」で、WordPress標準の余白設定から上と下のマージンを追加できる。入力は初期非表示とし、値と単位はテーマおよびコアの設定に従う。
- `style.spacing.margin.top`と`style.spacing.margin.bottom`に保存し、編集画面とフロントの外枠に適用する。個別解除や設定の初期化で、テーマと既存のスタイルによる余白に戻る。

## スライド表示数と子の幅

- スライド・カバーフローの「1画面に表示するスライド数」で`auto`を選ぶと、[スライダーアイテム](../slider-item/DESIGN.md)で指定した幅を使う。端末別の設定でも、`auto`が有効な範囲に適用する。
- 表示数を数値で指定した場合や1枚表示の既定値が使われる場合、Swiperが表示数と間隔から各スライドの幅を計算する。
- 既存の高さ・縦横比設定はスライダー本体の表示領域を制御する。アイテムの高さは子の外枠に適用する。
